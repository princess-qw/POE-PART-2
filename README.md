# RaceDay API

## Project Overview

RaceDay API is a RESTful web API developed using ASP.NET Core and .NET 9 to support event management and participant enrolments.

## Technologies Used

- C#
- ASP.NET Core Web API
- .NET 9
- Entity Framework Core
- SQL Server
- JWT authentication
- Swagger / OpenAPI
- xUnit
- GitHub Actions

## Main Features

- User registration and login
- JWT-based authentication
- Role-based authorisation
- Event management by Organisers
- Event enrolment by Participants

## Testing

The test suite will cover successful and unsuccessful registration and login, authentication requirements, role-based permissions, event management, and participant enrolments.

Tests will be run locally and through the GitHub Actions workflow.

## Continuous Integration

GitHub Actions is configured to build the application and run its automated tests on pushes and pull requests.
